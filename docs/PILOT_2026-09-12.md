# Первый пилот конвейера · 12 сентября 2026

По команде автора «Давай запустим» подготовлен локальный выпуск «Одни буквы — разные слова». Основание оформления — последние присланные референсы: светлая бумага, синий заголовок, фотография как часть композиции.

## Что входит

- Карусель из шести слайдов: фотообложка, три пары омографов, задание, ответы. JPG 1080×1350 и шесть MP4 со звуком по6секунд.
- Альтернативный Reels на том же тексте:14,6секунды, три пары появляются последовательно; полная памятка остаётся в конце5секунд и используется как обложка.
- Семь полных кадров Stories1080×1920: все шесть слайдов плюс обложка Reels. JPEG не содержит звука.
- Две готовые подписи с музыкальными кредитами, словарная проверка и происхождение фотографий.

Карусель и Reels — альтернативы одного выпуска. Для календаря выбирается одна версия; школьный материал учитывается в квоте только после назначения даты. Статусы обоих локальных черновиков — `pending`, дата отсутствует. Рабочая очередь `content/queue.json` не изменялась.

## Где смотреть

`outputs/pilot-2026-09-12/index.html` — галерея с вкладками, локальными видео, текстами и источниками. `contact-sheet.jpg` — все слайды на одном листе. `captions.txt` — подписи для выбранной версии.

## Как повторить сборку

В PowerShell задать `MEDIA_CONTENT_DIR` абсолютным путём к `outputs/pilot-2026-09-12/content`, а `FFMPEG_BIN` — путём установленного FFmpeg. Выполнить `node build-media.js 2026-09-12-omographs-carousel 2026-09-12-omographs-reel`. Общий сборщик создаёт медиа, manifest полного экспорта Stories и prepared-метаданные без изменения очереди.

После сборки: `node publish.js --validate-prepared`, затем `node check-content.js 2026-09-12-omographs-carousel` и `node check-content.js 2026-09-12-omographs-reel` в том же окружении. Для просмотра: `node scripts/preview-paper-pilot.js` и `node scripts/package-paper-pilot.js`.

Новый стиль включается только полем `visualStyle: "paper-collage"`. Старые шаблоны продолжают работать. Контроль контента теперь читает изолированную папку из `MEDIA_CONTENT_DIR`, как и сборщик. Видеорендер принимает ограниченные `rowSeconds` и `outroSeconds`; прежние значения по умолчанию сохранены.

Фактические результаты проверок сохраняются в `outputs/pilot-2026-09-12/result.json`, `verification.json`, `design/layout-check.json` и `editorial/final-review.md`. На этапе создания пилота публикация, push, запуск облачного расписания и новая автоматизация не выполнялись. Затем пользователь отдельно попросил перенос в облако; инструкции и контекст для него находятся в `CLOUD-HANDOFF.md`, команды там подходят для Linux.
