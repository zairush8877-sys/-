## Репосты

Новый экспорт делает Stories 1080×1920: исходник целиком вписывается в безопасную область с одинаковым масштабом по обеим осям. Карусель получает отдельный кадр на каждый слайд. Для Reels используется финальный кадр с подписью «Кадр из Reels»: это анонс, без движения, звука и нативного кликабельного стикера.

Учёт хранит результат каждого кадра и подтверждённый ID Stories. Повтор пропускает уже подтверждённые элементы. Ошибка подготовки допускает явный повтор; потерянный ответ после отправки блокирует повтор до сверки. В локальных workflows добавлена общая очередь исполнения публикаций, без изменения времени cron.

Для старых 32 опубликованных записей ID Stories не были сохранены. В журналах найдены один сбой попытки и один успешный результат без ID; для остальных 30 сопоставленного свидетельства нет. Это не означает 32 пропущенных репоста. Автоматический повтор старых материалов не запускался. Подробности и ограничения сохранности статусов — в [проверке репостов](REPOST_AUDIT.md).
